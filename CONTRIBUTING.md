# Contributing

This repository is the source of a commercial website. It is public so the claims
on the site can be checked — not because it is an open project.

## Pull requests

**Not accepted** for the site's copy, design, structure or pricing. Those are the
business, not a community artefact, and a well-meant rewrite of a price or a claim
would be a commercial change dressed as a contribution.

## What is genuinely welcome

- **Broken links, typos, and accessibility defects.** If something on the live site
  does not work, that is a real bug and I want to know. Open an issue using the
  template.
- **Security reports.** Do not open a public issue — see [SECURITY.md](SECURITY.md).
- **Corrections to the market figures** cited on the price page. If you have a
  better public source for DACH pricing, that improves the site for everyone.

## Work enquiries

This is not a contribution channel. If you want a website or SEO work, message
[@relaystack on Telegram](https://t.me/relaystack).

## If you are forking anyway

The [LICENSE](LICENSE) does not permit it. Read it before you spend time.
